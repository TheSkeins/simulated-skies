# simulated-skies
attempt at weather simulation in a 2d map
basic idea is that of a 100x100 (or more) grid of pixels
each pixel representing an object of terrain and an object of weather
terrain class should influence how weather forms and moves
terrain should have the following attributes: Albedo, Height, Terrain type (rock, forest, desert, river, grassland, body of water), temperature, humidity,
terrain type should influence albedo, humidity calculations and temperature retention
